# hkandan-hash.github.io

My portfolio site: https://hkandan-hash.github.io

It's a single `index.html` with no frameworks and no build step. The project cards are curated in the `PROJECTS` list in the script. Any new public repo on GitHub is added automatically through the GitHub API.

To add or edit a project, change its entry in `PROJECTS` and push. GitHub Pages redeploys within a minute.
